# Role Library — Built Environment, Science, and Field Operations

Bounded agent roles for **Built-environment, science, and field-operations support** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 6 skill(s).

## Skills

- `bsf-01-project-controls-agent`
- `bsf-02-design-document-coordinator`
- `bsf-03-field-observation-triage-agent`
- `bsf-04-scientific-literature-and-protocol-agent`
- `bsf-05-laboratory-data-steward`
- `bsf-06-sustainability-and-impact-analyst`

## Install

```
/plugin install role-library-built-environment
```
(after adding this repo as a marketplace)
