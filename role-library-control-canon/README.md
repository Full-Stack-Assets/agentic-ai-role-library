# Role Library — Control and Canon

Bounded agent roles for **Control and canon** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 6 skill(s).

## Skills

- `cmo-01-artist-operations-orchestrator`
- `cmo-02-persona-bible-curator`
- `cmo-03-voice-governor`
- `cmo-04-creative-director-agent`
- `cmo-05-quality-gatekeeper`
- `cmo-06-collaboration-coordinator`

## Install

```
/plugin install role-library-control-canon
```
(after adding this repo as a marketplace)
