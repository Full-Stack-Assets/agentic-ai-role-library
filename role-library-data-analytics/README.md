# Role Library — Data, Analytics, AI, and Experimentation

Bounded agent roles for **Data, analytics, AI, and experimentation** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 8 skill(s).

## Skills

- `daa-01-data-steward-agent`
- `daa-02-data-quality-monitor`
- `daa-03-analytics-insight-agent`
- `daa-04-forecast-and-scenario-agent`
- `daa-05-experiment-analyst`
- `daa-06-ml-model-operations-agent`
- `daa-07-ai-output-evaluator`
- `daa-08-decision-intelligence-agent`

## Install

```
/plugin install role-library-data-analytics
```
(after adding this repo as a marketplace)
