# Role Library — Software Engineering, Security, and Platform Operations

Bounded agent roles for **Software engineering, security, and platform operations** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 9 skill(s).

- `esp-02-software-implementation-agent`
- `esp-03-code-review-and-quality-agent`
- `esp-04-test-engineering-agent`
- `esp-05-devops-and-release-readiness-agent`
- `esp-06-reliability-monitor-and-incident-triage-agent`
- `esp-07-security-posture-analyst`
- `esp-08-identity-and-access-review-agent`
- `esp-09-technical-documentation-agent`
