# Role Library — Governance, Knowledge, and Enterprise Control

Bounded agent roles for **Governance, knowledge, and enterprise control** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 7 skill(s).

## Skills

- `gke-01-enterprise-workflow-orchestrator`
- `gke-02-policy-and-control-interpreter`
- `gke-03-approval-and-delegation-steward`
- `gke-04-audit-evidence-curator`
- `gke-05-knowledge-base-curator`
- `gke-06-research-and-source-verification-agent`
- `gke-07-records-and-retention-coordinator`

## Install

```
/plugin install role-library-governance
```
(after adding this repo as a marketplace)
