# Role Library — Healthcare, Public Service, Education, and Casework

Bounded agent roles for **Healthcare, public service, education, and casework** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 6 skill(s).
