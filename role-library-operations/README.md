# Role Library — Operations, Supply Chain, and Procurement

Bounded agent roles for **Operations, supply chain, and procurement** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 8 skill(s).

## Skills

- `osp-01-operations-planning-agent`
- `osp-02-supply-and-demand-signal-analyst`
- `osp-03-procurement-research-and-intake-agent`
- `osp-04-vendor-performance-monitor`
- `osp-05-process-excellence-agent`
- `osp-06-quality-management-agent`
- `osp-07-field-service-coordinator`
- `osp-08-asset-and-maintenance-intelligence-agent`

## Install

```
/plugin install role-library-operations
```
(after adding this repo as a marketplace)
