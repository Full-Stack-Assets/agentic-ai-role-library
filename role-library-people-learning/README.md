# Role Library — People, Learning, and Organizational Enablement

Bounded agent roles for **People, learning, and organizational enablement** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 6 skill(s).

## Skills

- `ple-01-workforce-planning-agent`
- `ple-02-talent-sourcing-research-agent`
- `ple-03-learning-experience-designer`
- `ple-04-performance-enablement-coach`
- `ple-05-employee-service-triage-agent`
- `ple-06-organizational-knowledge-facilitator`

## Install

```
/plugin install role-library-people-learning
```
(after adding this repo as a marketplace)
