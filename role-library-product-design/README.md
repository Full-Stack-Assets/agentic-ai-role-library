# Role Library — Product, Experience, and Design

Bounded agent roles for **Product, experience, and design** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 7 skill(s).

## Skills

- `pxd-01-product-discovery-agent`
- `pxd-02-product-requirements-agent`
- `pxd-03-user-research-synthesizer`
- `pxd-04-ux-flow-architect`
- `pxd-05-ui-system-designer`
- `pxd-06-prototype-and-experiment-agent`
- `pxd-07-experience-qa-agent`

## Install

```
/plugin install role-library-product-design
```
(after adding this repo as a marketplace)
