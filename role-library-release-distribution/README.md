# Role Library — Release and Distribution

Bounded agent roles for **Release and distribution** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 8 skill(s).

## Skills

- `cmr-01-release-calendar-manager`
- `cmr-02-release-packager`
- `cmr-03-metadata-and-credits-steward`
- `cmr-04-rights-and-licensing-monitor`
- `cmr-05-platform-optimization-agent`
- `cmr-06-playlist-and-editorial-pitching-agent`
- `cmr-07-global-distribution-coordinator`
- `cmr-08-royalty-and-revenue-tracker`

## Install

```
/plugin install role-library-release-distribution
```
(after adding this repo as a marketplace)
