# Role Library — Revenue, Customer, and Partnership Operations

Bounded agent roles for **Revenue, customer, and partnership operations** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 8 skill(s).
