# Role Library — Sector Overlay Roles

Bounded agent roles for **Sector overlay roles** from the Agentic AI Role Library. Each role ships as a Claude Code skill with an operating contract (mission, approved inputs, allowed work, required output schema, quality gate, handoff, stop conditions).

**Contents:** 8 skill(s).

## Skills

- `ovl-01-insurance-claims-support-agent`
- `ovl-02-real-estate-transaction-coordinator`
- `ovl-03-legal-matter-operations-agent`
- `ovl-04-insurance-banking-compliance-evidence-agent`
- `ovl-05-hospitality-guest-experience-agent`
- `ovl-06-retail-merchandising-insight-agent`
- `ovl-07-media-rights-operations-agent`
- `ovl-08-nonprofit-grant-operations-agent`

## Install

```
/plugin install role-library-sector-overlays
```
(after adding this repo as a marketplace)
